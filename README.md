# EV Fast Charge Website

This is a modern, high-performance website built for **EV Fast Company**, developed by **Ashok Nepal**.

The project is built using **Next.js 14**, **TypeScript**, and **Tailwind CSS**, focusing on speed, SEO optimization, and a clean user experience for EV charging solutions.

---

## 🚀 Project Overview

This website showcases EV charging products, solutions, and company information with a fully responsive and scalable design.

It includes:
- Product catalog with dynamic pages
- SEO-friendly routing
- Modern UI with Tailwind CSS
- Fast performance using Next.js App Router

## 🚀 Getting Started

### Install dependencies
```bash
npm install
````

### Run development server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

### Build for production

```bash
npm run build
npm start
```
